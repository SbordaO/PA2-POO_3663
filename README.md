# PA2 - Programación Orientada a Objetos

# Descripción del Trabajo
Mini aplicación web de cotización y validación de datos desarrollada en Java utilizando JSP y ejecutada sobre el servidor Apache Tomcat. El proyecto integra operaciones lógicas aplicando métodos de las clases `String` y `Math`.

# Instrucciones de Ejecución
1. Clonar o descargar el repositorio en tu máquina local.
2. Importar el proyecto como un Dynamic Web Project en tu entorno de desarrollo IntelliJ IDEA.
3. Configurar y levantar el servidor Apache Tomcat.
4. Ejecutar el archivo principal **`index.jsp`** en el navegador web para visualizar el formulario de cotización.
5. Ingresar los datos solicitados y presionar el botón de envío para procesar los resultados en **`resultado.jsp`**.
